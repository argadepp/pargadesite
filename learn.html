Your roadmap

DevOps learning paths

A practical sequence of topics to help you move from foundations to cloud-native engineering. Start with the fundamentals, then build and troubleshoot.

01
CLOUD ENGINEERING

AWS & Cloud Infrastructure

Build a strong understanding of cloud building blocks and how they fit together.

IAM & securityVPC & networkingEC2 & load balancingRoute 53Terraform

Suggested order: Cloud basics → networking → IAM → compute → infrastructure as code → resilient architecture.

02
CONTAINERS & GITOPS

Docker, Kubernetes & GitOps

Learn container packaging, cluster objects, deployment patterns and declarative delivery.

DockerPods & DeploymentsServices & IngressHelmEKSArgo CD

Suggested order: Docker → Kubernetes objects → networking → storage → Helm → GitOps → troubleshooting.

03
DELIVERY & AUTOMATION

CI/CD & Infrastructure as Code

Automate builds, tests, infrastructure plans and deployments with repeatable workflows.

Git & GitHubJenkinsGitHub ActionsTerraformTerragruntAtlantis

Suggested order: Git → pipeline basics → build/test → secrets → IaC plan/apply → approvals and rollback.

04
RELIABILITY

Monitoring, Logging & Observability

Use telemetry to understand application and infrastructure health, then investigate symptoms systematically.

PrometheusGrafanaLokiAlertingELKOpenTelemetry concepts

Suggested order: Metrics → dashboards → logs → alerts → SLI/SLO basics → incident troubleshooting.

05
FOUNDATIONS

Linux & Python for DevOps

Improve your ability to debug systems and automate repetitive operational work.

Linux commandsProcesses & networkingBashPythonREST APIsJSON/YAML

Suggested order: Shell basics → files and processes → networking → scripting → API calls → error handling.

06
SECURE DELIVERY

DevSecOps Foundations

Understand how security becomes part of planning, coding, building and deploying software.

Least privilegeSecrets managementImage scanningDependency scanningPolicy checks

Suggested order: Threat basics → identity and secrets → scanning → pipeline gates → image and runtime security.
