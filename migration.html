Example On-Prem Estate

Assume a company runs a classic three-tier application in its data center:

  • Web tier on VMware VMs behind F5 load balancer.
  • Java application tier on Tomcat and Linux VMs.
  • Oracle database with nightly backup jobs.
  • Jenkins server, shared NFS storage, monitoring, and old reporting tools.
1

Assess

Inventory applications, dependencies, traffic, compliance, RTO/RPO, and current monthly run cost.

2

Plan

Group workloads into migration waves and choose a 7R strategy for every app and platform component.

3

Migrate

Build landing zone, connect network, move data, cut over workloads, and validate operations.

4

Optimize

Right-size compute, improve automation, modernize CI/CD, strengthen observability, and tune cost.

7R Migration Strategies

Use the 7R model to decide the best target state for each workload, not just the fastest move.

R1

Rehost

Lift and shift workloads with minimal change.

Example: Move Tomcat VMs from VMware to Amazon EC2 using AWS Application Migration Service.

R2

Replatform

Make small cloud optimizations without changing core architecture.

Example: Move self-managed MySQL from a VM to Amazon RDS while keeping the app code mostly unchanged.

R3

Refactor

Redesign the application to use cloud-native patterns.

Example: Break a monolithic Java service into containers on EKS with SQS, Lambda, and managed databases.

R4

Relocate

Move the platform as-is to an equivalent cloud service.

Example: Move VMware workloads to VMware Cloud on AWS to exit a data center quickly.

R5

Repurchase

Replace an existing product with a SaaS or managed alternative.

Example: Replace an on-prem ticketing tool with Jira Service Management or ServiceNow SaaS.

R6

Retain

Keep a workload on-prem for business, risk, latency, or compliance reasons.

Example: Keep a factory control system in the local data center while connecting it through VPN or Direct Connect.

R7

Retire

Decommission applications that no longer provide business value.

Example: Shut down an old reporting portal after validating no users or jobs depend on it.
