01 · Understand the topic

What is Git & GitHub?

Git is a distributed version control system. It records changes to files over time so you can review history, experiment safely and collaborate. GitHub hosts Git repositories and adds pull requests, reviews, issues and automation.

Why is it useful in DevOps?

Infrastructure code, application code, Kubernetes manifests and pipeline definitions should be version controlled. Git gives teams a reviewable history and a reliable way to collaborate.

02 · Core knowledge

Important concepts to understand

Repository

A project folder tracked by Git, including its history.

Working tree & staging

Working tree contains edits. The staging area selects the changes for the next commit.

Commit

A snapshot with a message and unique identifier.

Branch

An independent line of work that lets you develop a change without modifying the main branch.

Merge & conflict

Merge combines histories. A conflict needs a human to choose the intended final content.

Remote & pull request

A remote is a shared repository. A pull request proposes and reviews changes before merging.

04 · Learn in sequence

Step-by-step learning plan

  1. Install Git and configure your name and email. Learn the difference between Git (version control) and GitHub (hosting/collaboration).
  2. Create a repository and practise status, add, commit, log and diff. Make small commits with clear messages.
  3. Create a feature branch, edit a file and switch between branches. Understand why main should stay stable.
  4. Create a GitHub repository, add it as a remote, push your branch and open a pull request.
  5. Review a pull request, respond to comments and merge it. Practise resolving a small merge conflict in a test repository.
  6. Add a README and .gitignore. Never commit passwords, API keys, private keys or Terraform state.
05 · Hands-on practice

Mini project / lab

Create a repository containing a simple web page and README. Make a feature branch, change the page, push it, open a pull request, merge it and inspect the final history.

Tip: Save your notes, commands, screenshots and troubleshooting findings in a GitHub repository. Your learning record becomes part of your portfolio.
