01 · Understand the topic

What is Bash & Python for Automation?

Scripting means writing small programs to perform repeatable tasks. Bash is useful for combining Linux commands; Python is a readable general-purpose language with libraries for APIs, files, data and cloud automation.

Why is it useful in DevOps?

DevOps engineers automate checks, deployments, backups, reports and operational tasks. A small reliable script saves time and reduces manual mistakes.

02 · Core knowledge

Important concepts to understand

Variables & data

Store values such as filenames, environment names or thresholds.

Conditions & loops

Choose what to do and repeat actions over a list.

Functions

Group reusable logic into named blocks.

Exit codes

A process returns 0 for success by convention and non-zero for failure.

Environment variables

Pass configuration without hard-coding it into source code.

JSON, YAML & APIs

Common formats and interfaces used by cloud platforms and automation tools.

04 · Learn in sequence

Step-by-step learning plan

  1. Learn shell basics: variables, quoting, pipes, redirection, exit codes and command substitution. Practise with echo, grep, awk, sed and sort.
  2. Write a Bash script that accepts an argument, validates it and prints a useful message. Add a shebang and executable permission.
  3. Learn Python variables, strings, lists, dictionaries, loops, conditions, functions and exceptions.
  4. Read and write text, JSON and YAML files. Use a virtual environment and install packages with pip.
  5. Call a public test API with Python requests. Handle timeouts, HTTP errors and malformed responses.
  6. Learn to read secrets from environment variables and avoid printing them. Add logging and meaningful exit codes.
05 · Hands-on practice

Mini project / lab

Create a disk-usage checker in Bash or Python. It should accept a threshold, print a warning when usage exceeds it, and return a non-zero exit code on failure. Test both success and failure paths.

Tip: Save your notes, commands, screenshots and troubleshooting findings in a GitHub repository. Your learning record becomes part of your portfolio.
