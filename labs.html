Hands-on DevOps labs

Use these project outlines to practise common engineering workflows. Each lab is a suggested learning exercise; add your own repository links as the walkthroughs become available.

K8sOBSERVABILITY
Intermediate

Kubernetes monitoring with Prometheus & Grafana

Explore metrics collection, dashboards, alert rules and workload health on a local or test Kubernetes cluster.

Lab checklist

  • Prepare a local cluster and install the monitoring stack.
  • Inspect node, pod and workload metrics.
  • Create a dashboard and test an alert rule.
  • Document resource usage and cleanup steps.

Suggested tools: Kubernetes, Helm, Prometheus, Grafana.

{ IaC }CLOUD INFRASTRUCTURE
Intermediate

Terraform AWS infrastructure workflow

Practise infrastructure planning and change review before creating or modifying cloud resources.

Lab checklist

  • Define a small network and compute configuration.
  • Run format, validate and plan checks.
  • Review state, variables and outputs.
  • Apply only in a test account, then destroy resources and verify cleanup.

Suggested tools: Terraform, AWS, GitHub Actions or Jenkins.

↻DECLARATIVE DELIVERY
Intermediate

GitOps deployment with Argo CD

Learn how Git becomes the desired state source and how an operator reconciles the cluster.

Lab checklist

  • Deploy a small sample application.
  • Connect a Git repository and define an application.
  • Change a manifest and observe sync status.
  • Test drift correction and rollback in a disposable environment.

Suggested tools: Kubernetes, Git, Argo CD, Kustomize or Helm.

CI/CDAUTOMATED DELIVERY
Beginner → Intermediate

Build and deploy with GitHub Actions

Create a pipeline that checks code quality and builds a small application before deployment.

Lab checklist

  • Trigger workflows on pull requests and pushes.
  • Add lint, test and build jobs.
  • Store credentials as repository secrets where appropriate.
  • Publish a build artifact and document deployment gates.

Suggested tools: GitHub Actions, Docker, a sample app and a test deployment target.
