01 · Understand the topic

What is Monitoring, Logging & Observability?

Observability is the ability to understand what is happening inside a system from the signals it produces. Metrics show numeric trends, logs record events, and traces follow requests across components.

Why is it useful in DevOps?

A service can be running but still be slow or failing for users. Observability helps detect symptoms, investigate causes, measure reliability and validate improvements.

02 · Core knowledge

Important concepts to understand

Metrics

Time-series measurements such as request rate, latency, errors and resource use.

Logs

Timestamped event records that explain what an application or system did.

Traces

A connected view of one request as it travels through multiple services.

Prometheus

Collects and stores metrics and evaluates alert rules.

Grafana

Builds dashboards and explores data from supported sources.

Alerting

Notifies responders when a meaningful condition or symptom occurs.

SLI & SLO

An SLI measures service behaviour; an SLO defines a target for that measure.

04 · Learn in sequence

Step-by-step learning plan

  1. Understand the difference between monitoring and observability. Learn the golden signals: latency, traffic, errors and saturation.
  2. Inspect application and system logs. Learn timestamps, severity, structured fields, correlation IDs and log levels.
  3. Learn Prometheus basics: scrape targets, exporters, time-series labels, PromQL and alert rules.
  4. Build a Grafana dashboard with a few useful panels. Avoid high-cardinality labels and misleading aggregations.
  5. Understand alert quality: actionable symptoms, thresholds, duration, severity, ownership and runbooks.
  6. Learn tracing concepts and OpenTelemetry at a high level. Connect telemetry to user experience and SLI/SLO targets.
05 · Hands-on practice

Mini project / lab

Deploy a small app and monitoring stack in a local cluster. Build a dashboard for CPU, memory and request metrics, generate a test failure, inspect logs and create one actionable alert.

Tip: Save your notes, commands, screenshots and troubleshooting findings in a GitHub repository. Your learning record becomes part of your portfolio.
